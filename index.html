使用提示

1. 手机需与网关主机处于同一 WiFi 网段（如网关 192.168.1.x，手机也应为 192.168.1.x）。
2. 默认认证为 user / password，与协议文档一致，可在绑定页修改。
3. 若浏览器直连受跨域(CORS)限制，请使用 Android 壳工程打包的 APK（WebView 已放开该限制）。
4. 页面需以 http(s) 或本地文件方式打开；不要通过 https 页面访问 http 网关（会被浏览器拦截）。
5. 设备长按名称可重命名（保存在本机）。
